GILDED VAULT — A Midnight Heist: a top-down 2D stealth game. Slip past patrolling guards and sweeping security cameras, steal five golden treasures from the Grand Museum, and reach the EXIT before the alarm fills.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — move with WASD or arrow keys, grab all five treasures, and escape through the EXIT. Seen by a guard or a camera, the alarm rises; a full alarm means caught. Press Space to restart.
